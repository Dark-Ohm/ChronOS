## Контекст

Ты сделал выбор схемы через `CHRONOS_THEME` — это был осознанный MVP.
Теперь доводим до продукта: схема должна жить в конфиге и меняться
БЕЗ рестарта шелла (хот-релоад — заявленный приоритет проекта,
ARCHITECTURE §9).

Что уже есть в дереве и переиспользуется как есть:
- **паттерн конфига:** `~/.config/chronos/` + toml —
  образцы `monitor.toml` (`crates/app/src/monitor.rs`), `dock.toml`
  (`dock/config.rs`), `projects.toml` (`project_switcher/`). Бери
  load/save/дефолт-при-отсутствии 1:1 оттуда, не изобретай.
- **inotify-вотчер:** уже используется в проекте (applications-сервис,
  luau-плагины) — крейт `notify`, дебаунс. Образец брать оттуда.
- `builtin_schemes()` + `Theme::select_scheme(...)` — твои, готовы.

Правки после твоего №1, знать: `status.*` у светлой теперь **Latte**
(не Mocha) — тест `light_scheme_status_is_latte_not_mocha` это
стережёт; и появился `on_fill()` (контент поверх заливок). Не откати.

## Задача

1. **`~/.config/chronos/theme.toml`** — `{ scheme = "Light" }` (имя из
   `builtin_schemes()`). Нет файла/битый/неизвестное имя → дефолтная
   тёмная + `tracing::warn!`, файл НЕ перезаписывать молча.
2. **Приоритет:** `CHRONOS_THEME` (env) перебивает конфиг — удобно для
   смоков. Порядок: env → конфиг → дефолт. Зафиксируй в отчёте.
3. **Hot-reload:** правка `theme.toml` → тема применяется БЕЗ рестарта.
   Глобал `Theme` переустанавливается и все окна перерисовываются
   (`cx.refresh_windows()`; смотри, как это делает hot-reload плагинов).
   Бар/попапы читают `Theme::global(cx)` в render, так что отдельно их
   трогать не должно понадобиться — если понадобится, это сигнал, что
   где-то тема закеширована: НЕ чини чужой виджет, перечисли в отчёте.

## Кровные факты (не наступи)

- Тики/таймеры/UI — GPUI executor (`cx.spawn` +
  `background_executor().timer`), НЕ tokio (DECISIONS «Runtime split»).
  inotify — отдельный OS-тред, как в applications-сервисе.
- `cx.background_spawn` без `.detach()` — баг (drop = cancel).
- `let _ = fallible()` запрещён — ошибки чтения/парса конфига логируй.
- `Theme` derive Copy — `SharedString` в поля нельзя.

## Зоны

(минимально). **НЕ трогай:** виджеты бара, попапы (Grok №16 и Mimo №12

(Hermes). Поимённый add.

## Верификация

- build release + тесты зелёные; юнит-тесты: приоритет env>конфиг>дефолт,
  битый toml → дефолт без паники.
- **Живой смок (главное):** запусти шелл БЕЗ переменной с
  `theme.toml{scheme="Light"}` → бар светлый; потом **на живом шелле**
  поменяй файл на тёмную → бар перекрашивается сам, без рестарта, grim
