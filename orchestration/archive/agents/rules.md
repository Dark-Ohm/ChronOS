# orchestration/agents/rules.md — общие правила для всех миньонов

Читает каждый минион в начале холодной сессии (ссылка на этот файл стоит в
каждом `orchestration/agents/<ИМЯ>.md`). Роль архитектора и живой список
дисциплины архитектора — `ARCHITECT.md` (корень репо), не здесь.

## Lifecycle (обязателен)

| Папка | Роль |
|---|---|
| `orchestration/tasks/active/` | Твоё активное задание лежит здесь: `TNNN-slug.md` |
| `orchestration/tasks/report/` | Сюда кладёшь отчёт по готовности: `TNNN-slug-report.md` |
| `orchestration/tasks/report-log/` | Принятые отчёты — **не пишешь сюда сам** |
| `orchestration/tasks/done/` | Принятые брифы — **не пишешь сюда сам** |
| `orchestration/tasks/rejected/` | Отклонённое — архитектор решает |

Ты никогда не перекладываешь файлы между `report-log/`/`done/`/`rejected/` —
это делает архитектор при приёмке. Твоя часть — брать бриф из `active/`,
класть отчёт в `report/`.

## Race-map (несколько задач делят файл)

Если бриф пересекается по файлам с параллельной задачей — граница строк/
модулей описана в самом брифе явно («ты трогаешь X, НЕ трогаешь Y»). Если
пересечение всплыло по ходу работы и в брифе не описано — СТОП, вопрос
архитектору, не решай сам чьи строки чьи.

## Фрод-таблица (не делай)

- Не выдавай «тесты зелёные» за «живой смок работает» — это разные вещи.
  UX/оконный код проверяется ТОЛЬКО release-сборкой + живым прогоном
  (`RUST_LOG=info` + grim), не юнит-тестами.
- Не полагайся на имя/размер скриншота как доказательство — открой картинку
  сам и опиши, что на ней реально видно.
- Не помечай PASS то, что не перепрогонял. Если что-то нельзя проверить живьём
  в твоей среде (нет GUI-сессии, `ydotool` ненадёжен) — честно пиши PENDING,
  не выдавай синтетический клик за подтверждённый.
- Полный разбор фрод-класса ошибок и живых инцидентов — `HANDOFF.md` разделы
  «Правила поля» и «Кровные факты», и `ARCHITECT.md` §I do NOT. Не дублируется
  здесь — читай там.

## Git

- Поимённый `git add`, никогда `git add -A`/`.`.
- Никогда не коммить без явного разрешения — оставляешь дерево + отчёт,
  коммитит архитектор (если бриф не говорит иначе явно).
- `pkill -x chronos`, никогда `pkill -f` (убивает и вызывающий шелл).
- Никогда `git stash`/`checkout`/`mv` чужого uncommitted WIP. Чужой
  некомпилящийся WIP в дереве = СТОП и вопрос архитектору, не обход.
- Изоляция для верификации — `git worktree add` соседом репо (не `/tmp` —
  path-депы на `../Source` ломаются).

## История

Прошлые задания всех миньонов теперь пронумерованы сквозным T-ID —
`orchestration/tasks/MIGRATION.md` (реестр T-ID ↔ агент ↔ коммит ↔ старый
путь). Не ищи историю в `orchestration/agents/archive/` — это дореформенный
архив, оставлен только как raw-источник миграции, не актуальный журнал.
