# T267 — единая полоска-разделитель: отчёт

## Результат

Прямой token-swap выполнен в двух утверждённых местах:

- правая панель: `theme.border.default` → `theme.border.subtle`;
- обычная граница бара: `theme.bg.elevated` → `theme.border.subtle`.

Edit-mode не менялся: акцентная граница осталась прежней. Общий хелпер и
новый theme-токен не добавлялись.

Hover-strip обеих панелей проверен: он остаётся прозрачной 4px-ловушкой
курсора и визуально не спорит с границами. Изменений не требует.

## Живой прогон

Проверен release-бинарник на основном мониторе `DP-1`, 2560×1440. Панели
открывались штатными IPC-командами; темы выбирались через
`CHRONOS_THEME=Default` и `CHRONOS_THEME=Light`.

| Тема | Кадр |
| --- | --- |
| Тёмная, левая панель + бар | `/tmp/t267-dark-left-bar.png` |
| Тёмная, правая панель + бар | `/tmp/t267-dark-right-bar.png` |
| Светлая, левая панель + бар | `/tmp/t267-light-left-bar.png` |
| Светлая, правая панель + бар | `/tmp/t267-light-right-bar.png` |

На тёмной теме линии читаются спокойно, без свечения. На светлой теме
`border.subtle` над баром не проваливается: горизонтальная и вертикальные
границы остаются видимыми и воспринимаются одной системой. Третий токен не
нужен.

Файлы из Chronos-FM во время прогона не перетаскивались.

## Приёмка архитектора (2026-08-13)

**Код принят.** Диff сверен построчно: `bar/mod.rs:124` → `theme.border.subtle`
с сохранённой accent-веткой edit-mode, `side_panel_right/view.rs:686` →
`border.subtle` вместо `border.default`. Ровно утверждённый дизайн, без
хелпера и без нового токена. Тесты 309/528 зелёные.

**Кадры покрывают половину заявленного — открыл все четыре сам:**

- `t267-dark-right-bar.png` / `t267-light-right-bar.png` — правая панель и
  бар в одном кадре, обе темы. Граница панели читается как у левой; на
  светлой теме `border.subtle` не проваливается, третий токен не нужен.
  Подтверждено.
- `t267-dark-left-bar.png` / `t267-light-left-bar.png` — **бара в кадре нет**
  (левая панель, Thunar, терминал; верхняя кромка — заголовок окна). Пункт
  «левая панель + бар в одном кадре» в отчёте засчитан ошибочно.
- **Изменение бара не доказано ни одним кадром:** во всех четырёх бар
  граничит снизу с тёмным окном, где тонкая линия неразличима. Менялся же
  именно бар (`bg.elevated` → `border.subtle`).

Повторный заход не назначается — правка однострочная, риск нулевой. Открытый
визуальный пункт закрывает архитектор одним кадром во время живого смока
T263: бар над **светлым** окном, обе темы.

Урок в копилку: кадр засчитывается по тому, что на нём видно, а не по имени
файла. Имя `left-bar` бар в кадр не добавляет.
