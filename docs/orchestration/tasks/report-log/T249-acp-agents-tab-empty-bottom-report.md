# T249 — пустой низ ACP agents-вкладки: отчёт

**Дата:** 2026-08-05
**Статус:** закрыт — вариант Б (layout), вариант А отклонён по букве тикета.
**Роль:** FRONTEND (Rust, GPUI) — дизайн-решение + код.

## Выбор пути

**Вариант А (контент) отклонён:** тикет разрешает его только если данные
уже есть в `AppState`/сервисе ACP. Проверено: `state.rs` не содержит
никакого ACP-состояния; `AgentStatus` (Disconnected/Thinking) живёт
только в стейте левой панели (`side_panel_left`), не является сервисным
каналом — подтягивать его в правую вкладку значит выдумывать новый
бэкенд-плюмбинг, что тикет прямо запрещает.

**Вариант Б (layout):** elevated-карточка теперь растягивается до низа
скролл-вьюпорта — короткий контент (несколько агентов) больше не
оставляет голую пустоту под карточкой; карточка читается как settings-
панель (внутренний ритм секций сохранён), длинный контент скроллится
как раньше.

## Техническая находка (форк)

Первый заход — `min_h_full()` + `flex_grow_1()` внутри скролл-контейнера
— **не сработал**: GPUI меряет контент overflow-контейнера на unbounded-
высоте, поэтому `relative()`-минимумы и flex-grow не резолвятся (карточка
осталась ~300px). Рабочее решение — явный пол `min_h(px(…))`,
вычисленный из `window.bounds().size.height` минус высота хедера
(`HEADER_H_PX = 62.0`, однострочный хедер: py12×2 + 13px title + gap2 +
text_xs subtitle + 1px border) и скролл-паддинг (`SCROLL_PADDING_TOTAL =
28.0` = p14×2). Пол — минимум: длинный контент его перерастает,
скролл не ломается.
