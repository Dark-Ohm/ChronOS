# Отчёт T252 — паттерн empty-state для вкладок правой панели

Дата: 2026-08-13. Ветка: master. Тип: дизайн-решение (не код).

## Что сделано

Пройдены все вкладки `crates/app/src/side_panel_right/tab/*.rs` единым
чек-листом «что показываем, когда нечего показывать» — по живому коду
после слияния T246/T248/T249, как предписывал тикет. Полная таблица —
в `done/T252-empty-state-pattern-audit.md`.

Выведено шесть легитимных приёмов пустоты: hero / inline-строка /
compact-collapse / скрытие секции / растягивание карточки до низа /
honest placeholder. Решение — **матрица выбора приёма по семантике
пустоты** + планки-запреты (empty ≠ error; моки запрещены безусловно;
error даёт capability + путь восстановления; placeholder без сроков).
Записано в `docs/DECISIONS.log` (2026-08-13).

## Приёмка — согласовано с одной поправкой (2026-08-13)

Архитектор сверил с деревом, опорные точки аудита подтверждены живьём.
Поправка, внесённая до заведения follow-up:

1. «нет дисков» — НЕ единственная русская строка: там же кнопки
   «монтировать»/«размонт.»/«извлечь». Вычищается весь блок дисков
   (4 строки) одним куском. Запись в DECISIONS.log и таблица исправлены
   с явной пометкой о первой редакции.
2. Языковая планка звучит теперь «английский, **кроме локали
   даты/времени**»: `MONTHS_RU` (power_row.rs + bar clock) — осознанный
   формат локали, согласованный с баром. Исключение зафиксировано явно,
   чтобы его не «починили» задним числом.

Замечание приёмки: номера строк в таблице дрейфуют — T269 ищет вхождения
по тексту строки.
