## Заход 1 (параллельная сессия, `/tmp/t223-captures-live-2/`, HEAD в её момент — до T244/T231-width фиксов)

### Снято чисто (19 кадров)

  floating kitty ещё в кадре — стол не идеально пуст).
- 6 Developer-вкладок × 2 темы (12 файлов) через `select-tab:<id>`.
- `dark-bar-pill.png`, `dark-bar-floating.png` — через прямую правку

- `dark-bar-edit-mode.png` — `toggle-edit-mode`, подтверждено логом.
- `dark-right-rail-collapsed.png` — 40px, `hyprctl layers` подтверждает.
- `dark-left-panel-empty.png` — левая панель докнута, тред пуст.

### Живой инфраструктурный баг, пойманный в процессе
Первый прогон капчи уронил рендер шелла целиком — `can't render at a zero
size` шквалом, весь layer-shell chrome пропал из `hyprctl layers`, процесс
не падал. Причина — **гонка с другой параллельной сессией**, дёргавшей
`chronos-ipc select-tab:*` на том же живом инстансе одновременно.
Потребовался `chronos-stop`/`chronos-start`. **Вывод: не гонять
`chronos-ipc` из двух сессий на одном живом шелле — может уронить рендер.**

### Блокер ввода, зафиксированный этим заходом
`wtype` печатает в фокус Wayland-сита компоситора, а не в окно, на которое
GPUI навёл `window.focus()` внутри своего дерева. Проверено: `expand-left`
докает панель и зовёт `window.focus(&composer_focus, cx)` на GPUI-уровне,
но реальный seat-фокус остаётся на kitty — текст ушёл в терминал, композер
ChronOS остался пустым. `ydotool` (клики) — известно нерабочим.

**Итог захода 1:** 19/22 обязательных кадров недостижимы синтетическим
вводом. Рекомендация отчёта — IPC-команда `compose-and-send:<text>`,
пишущая прямо в `InputState` композера, минуя Wayland seat.

**Важно: эта рекомендация уже реализована в T241 (принят той же ночью,
коммит из серии `437bb11`) — независимо, до того как этот отчёт был
дописан.** См. заход 2 ниже — команда опробована живьём.

## Заход 2 (я, архитектор, по прямому запросу «гоняй их ты»), `/tmp/t223-captures-2026-08-05/`, HEAD `17bde3ce8`

### Что пошло не так до меня и как исправил
Full-monitor снимки (`grim -o <output>`) ловили посторонние окна на столе.
Исправлено: **все кадры — строгий кроп по геометрии `hyprctl layers`** для
каждого слоя, не полноэкранные снимки — структурно исключает посторонние
окна физически вне кропа.

`chronos` в эту загрузку выбрал **HDMI-A-1**, не DP-1 (динамическая логика
«pult display») — съёмка велась там.

### Ложная тревога, ставшая находкой
Первые попытки принял за контаминацию чужим kitty-окном («Claude Code /
Allow / Deny» поверх System-вкладки). Расследовал:
**это не контаминация — это сам ChronOS.**
`crates/app/src/side_panel_right/permission.rs:1` — дословно: *«Static
permission card (Claude Code mock) — no backend wiring»*, подключена в
`system.rs:17`, рендерится **постоянно** на дефолтной System-вкладке в
обеих темах. Пользователь подтвердил живьём: «этот alloy deny он
персистентен там как недоделка, всегда перед глазами». Ушла топ-пунктом
в `T223-design-audit-report.md`.

Текст реально долетел в поле композера (видно на кадре 17, обрезан
шириной), т.е. T241-фикс работает на уровне записи в `InputState`. **НО:**
(1) отправка не произошла автоматически — тред остался «No messages yet»,
похоже команда только заполняет поле, не сабмитит; (2) **ширина левой
панели просела до 160px** вместо нормальной докнутой ~352-400 после
`compose-and-send` + повторных `expand-left` — не восстановилась. Это
похоже на тот же класс проблемы, что T242/T243 (width desync на панелях),
только на **левой** панели и с другим триггером (текст в композер, не
resize/select-tab). **Не чинил — не входило в scope этого захода, честно
зафиксировал для новой заявки.**

### Чего всё ещё нет (после обоих заходов, объединённо)

- Виджет раскладки клавиатуры (клик-цикл) — NOT CAPTURED, нужен клик.
- Редактор в режиме правки — NOT CAPTURED, нужен клик по файлу + Edit.
- **Левая панель — реальный ответ агента в треде** — частично разблокировано
  (`compose-and-send` пишет текст), но отправка не сработала автоматически
  в этом прогоне — нужен доп. IPC-триггер `send` или ручной Enter.
- Композер + открытый dropdown модели — NOT CAPTURED, нужен клик.
- Popup громкости/OSD — NOT CAPTURED, нет IPC.
- Попап уведомлений/трей — NOT CAPTURED, нет IPC.
- Drag ручки ресайза, hover-strip peek клипы — нужен синтетический курсор.
- Правый рейл Edit Mode (T219 стрелки/рамка) — нет отдельной IPC-команды,
  `toggle-edit-mode` рейл не переключает (проверено в заходе 1).
- Gamer-рейл (Library/Captures) — не снимал (сверх обязательного минимума).

### Рекомендации
1. **`ydotool`/`uinput`-блокер** — отдельная давняя задача, без неё клики
   физически недостижимы. Не чинить в рамках T223/T233.
2. **`compose-and-send` не сабмитит и валит ширину левой панели** — новый
   тикет (не заводил сам, по директиве «без приёмок» просто фиксирую факт).
3. Дисциплина кропа по `hyprctl layers` решает проблему «чужие окна в
   кадре» структурно — дальше можно не переживать за идеально пустой стол.
