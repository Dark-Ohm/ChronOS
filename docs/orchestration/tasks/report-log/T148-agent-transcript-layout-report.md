# T148 — транскрипт агента: порядок блоков, живое размышление, сворачивание

## Что сделано

### Д1 — Reasoning растёт видимо (был обрезан на 80px)

Убрал `.overflow_hidden().max_h(px(80))` из блока `thought`, заменил на
`.overflow_y_scroll().max_h(px(300))`. Теперь текст размышления растёт до
300px, после чего появляется внутренний скролл. Прилипание к низу
обеспечено через `scroll_to_bottom()` в обработчике `ThoughtChunk`.

### Д2 — Кнопка сворачивания

Добавлен кликабельный заголовок `Reasoning ⌄` / `Reasoning ⌃` над телом
размышления:
- **Во время стриминга** — развёрнут принудительно (`is_last && streaming_active`)
- **После завершения хода** — автоматически сворачивается
- **Ручной клик** — переключает состояние (хранится в
  `ChatView.collapsed_reasoning: HashSet<usize>`)

### Д3 — Порядок блоков исправлен

Был: `content → reasoning → tool_cards`
Стал: `tool_cards → reasoning → content`

### Д4 — Ответ генерируется внизу

`content` теперь последний ребёнок агентского пузыря. Растущий ответ
(TextChunk) дописывается в `msg.content` и отображается под размышлением
и тулами, а не наверху.

### Сопутствующие правки composer.rs

- `ThoughtChunk` теперь вызывает `chat.scroll_to_bottom()` (как TextChunk)
  и удаляет сообщение из `collapsed_reasoning` (force expand во время стриминга)
- После завершения стриминга (ok/error/timeout/cancel) размышление
  автоматически сворачивается

### Технические детали

- Изолировал `reasoning_toggle = cx.listener(...)` до вызова
  `render_tool_cards`, чтобы обойти Rust 2024 RPIT capture rules (E0502)
- Добавил `+ use<>` на оба RPIT-функции (`render_tool_cards`,
  `render_message`) — требуется для корректной дедупликации lifetime
- `overflow_y_scroll()` требует `.id()` на элементе (StatefulInteractiveElement)
