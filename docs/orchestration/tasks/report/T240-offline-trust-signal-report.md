## Решение (записано в `docs/orchestration/tasks/active/T240-offline-trust-signal.md`)

**Принцип: сигнал читается, но не шумит.**

- Бар не трогаем (плотность T234), onboarding не существует — отпадает.
- **ACP settings** — под шапкой, рядом с локальным процессом: подпись
  `local only · no network · no telemetry` (язык `section_header` /
  `setting_label` из T231 уже есть).
- **About / Build info** (`bar_settings.rs`) — одна mono-строка:
  `offline by design — no network · no telemetry`.

Отклонено: бейдж/иконка в баре (противоречит T234), onboarding
(не существует), tooltip-only (нечитаемо без ховера, а тест доверия —
статичный кадр).

## Почему так

Пользователь, тыкая «customize», в первую очередь видит System settings
(T231-аргумент). ACP settings — поверхность, где виден агент; там уже
косвенно читается локальный спавн (`hermes acp --accept-hooks`) — делаем
явным. About — вторит уже существующей секции, статично и дёшево.
