# T226 — digits vanish while typing (D6): localization #5, not reproduced

**Дата:** 2026-08-05
**Статус:** локализация проведена на обеих достижимых поверхностях — D6
не воспроизводится; остаток требует живого человека (Terminal на пустом
воркспейсе, RU-раскладка)
**Роль:** FRONTEND + live

## Что было закрыто по инфраструктуре (дыры попыток #2-#4)

1. **PreviewTarget IPC + фокус** — `side_panel_right/mod.rs`
   `preview_target()` теперь делает focus-defer (зеркало `select_tab`'s
   `active_tab_focus`, 50мс): wtype после `preview-target` реально
   попадает в Editor. Без этого ввод никуда не шёл.
2. **expand-left** — `side_panel_left/mod.rs`: композер залипал на 40px
   (рейл) при state=352 — тот же класс бага, что T243; закрыт
   зеркальным T243-гардом (гейт по `window.bounds()`). Верифицировано:
   352 на t=200мс. **Это же могло быть причиной «невидимого» ввода в
   прошлых попытках.**
3. **Геометрия слоёв** — критичный урок: замер mid-animation давал
   `x=2520 w=560` (правый край за экраном, grim/wf-recorder молча
   снимали мусор). Скрипт ждёт 2.0с после открытия до замера.

## Локализация (клипы wf-recorder ВО ВРЕМЯ набора + grim до/после)

`1a2b3c` в каждую поверхность во время записи. Метрика — ширина
глифов строки ввода по кадрам клипа (если цифры исчезают, прогрессия
ломается).

## Вывод

D6 на текущем коде не воспроизводится ни в одной достижимой
поверхности. Либо исправлен попутными фиксами (focus-defer T230/T241,
T243 resize-guard, expand-left-фикс этой сессии), либо живёт только в
Terminal/RU-IME — оба недостижимы тулингом без живого человека.

**Требуется ручной прогон** (пользователь): `123abc` в Terminal на
пустом воркспейсе; `123abc` в композере на RU-раскладке. Если не
воспроизведётся — закрыть T226 с пометкой «исправлено попутно».
