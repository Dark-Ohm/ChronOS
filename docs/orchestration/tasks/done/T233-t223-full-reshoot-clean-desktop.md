# T233 — T223 пересъёмка целиком, чистый стол (без kitty поверх кадра)

**Роль:** оператор съёмки (не обязательно vision-модель — просто нужен
живой ChronOS + доступ к экрану; сама критика — отдельный заход после).
**Источник:** `docs/orchestration/tasks/report/T223-design-audit-report.md`,
топ-10 п.1, п.8, п.9 (объединены — это один и тот же дефект материала:
kitty-терминал текущей агентской сессии перекрывает кадр).
**Приоритет:** P0 для самого аудита — без этого T223 физически не может
дать вердикт "продукт или демка", критик прямым текстом сказал: "без
левой панели агента это не ChronOS, а настройки Hyprland с красивым
System-tab".

## Что пошло не так в предыдущем заходе

Из 22 обязательных кадров брифа (`T223-design-audit-omnimodal.md` часть
A) в наличии было 6 поверхностей × 2 темы = 12 файлов. На **всех 13**
статичных кадрах и **всех 3** извлечённых кадрах клипа `theme-flip.mp4`
окно kitty (в котором писался этот же аудит) занимало 55-100% экрана.
`00-current.png` — та же болезнь, ChronOS не виден вообще.
`select-tab-cycle.mp4` — 2 из 4 кадров тоже чистый kitty.

## Что сделать

1. **Перед съёмкой — закрыть/свернуть все посторонние терминальные окна
   на рабочем столе DP-1.** Это включает kitty-сессии с агентами (эту
   в том числе, если технически возможно снимать из другого источника —
   например, headless-скрипт без видимого терминала, или окно на
   HDMI-A-1 вместо DP-1). Перед каждым `grim`/`wf-recorder` вызовом —
   `hyprctl clients -j`, убедиться что на целевом мониторе нет
   посторонних floating/tiled окон поверх шелла.
2. Пройти **весь** чек-лист Части A `T223-design-audit-omnimodal.md`
   (строки 30-56) — все 22 обязательных кадра, не только 6 из 12
   Developer-вкладок:
   - Бар: full / pill (`fraction:0.7`) / floating / Edit Mode / keyboard
     layout widget клик-цикл.
   - Правый рейл свёрнутый отдельным кадром (геометрически отделённым
     от контент-панели, не "попутно" на кадре с открытой панелью).
   - Все 6 вкладок Developer раскрытыми (уже частично есть — переснять
     заново на чистом столе).
   - Edit Mode правого рейла.
   - Редактор в режиме правки (курсор, открытый `.md`).
   - **Левая панель целиком** — это то, чего вообще не было: тред с
     ответом агента (живой, не пустой), шапка-кластер крупным планом
     (сигил+лампочка, T229), композер+dropdown модели открыт.
   - Док, лаунчер, попап громкости/OSD, тост уведомления, попап
     уведомлений/трей.
3. Клипы (`wf-recorder`, координаты из `hyprctl layers`, не на глаз):
   - `theme-flip` — переснять целиком, оба переключения, ChronOS должен
     быть виден на 100% кадров, не kitty.
   - `select-tab-cycle` — переснять, все кадры должны показывать
     реальное переключение вкладок правой панели.
   - Новые: one-click rail expansion/collapse, hover-strip peek, resize-
     handle drag, Edit Mode toggle-анимация бара, Follow ON/OFF, toast
     appearance/dismissal.
4. Сложить всё в `/tmp/t223-captures-<новая-дата>/` (тот же формат:
   `frames/`, `clips/`, `meta/` с `hyprctl layers -j`, manifest, SHA256).

## Инструмент для программного управления панелями (T226 tooling)

IPC-команды уже есть и работают (живьём проверено архитектором
2026-08-04): `chronos-ipc select-tab:<alias>`, `chronos-ipc preview-target:
<path>`, `chronos-ipc expand-left`, `chronos-ipc toggle-theme`. **Известное
ограничение:** `select-tab:terminal` не работает — `Terminal` не входит
в tab-сет `WorkspaceMode::Developer` (`tabs.rs:565-572`), не пытаться.
Валидные алиасы для Developer: system, files, preview, hyprlandbinds
(или как парсится в `PanelTab::parse_id`, свериться), acpsettings,
editorsettings.

## Верификация

Живой `hyprctl layers -j` для каждого кадра, сохранённый в `meta/` —
доказательство, что снят реальный ChronOS-слой, а не постороннее окно
поверх. Manifest со списком файлов, размерами, SHA256SUMS (как в
предыдущем evidence pack — формат был правильный, повторить).
