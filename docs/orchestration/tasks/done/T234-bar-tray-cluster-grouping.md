# T234 — Бар: визуальная группировка правого трей-кластера

**Роль:** FRONTEND.
**Источник:** `docs/orchestration/tasks/report/T223-design-audit-report.md`,
находка #1 (P1), топ-10 п.2.
**Приоритет:** P1.

## Находка (дословно)

Область x≈2100-2560, y≈0-35 внутри `bar: 0,0,2560,35`. Часы + трей-иконки
+ числовые счётчики + `US` + `Developer` + `ChronOS master▾` идут единой
плотной строкой без визуальных пауз между смысловыми группами (время /
сеть-батарея-звук / раскладка / режим / проект). Читается как типичный
polybar/waybar-статус-лайн, не как продуктовый DE-бар. Воспроизведено на
всех 12 кадров аудита (dark+light во всех вкладках) — не случайность
конкретного состояния.

## Что нужно

Ввести два уровня отступа в правой секции бара:
- **4px** между виджетами внутри одной смысловой группы.
- **12-16px** между группами: время | сеть/батарея/звук | раскладка
  клавиатуры | режим (Developer/Gamer) | проект.

Второстепенные числовые счётчики (down/up KB/s и подобные) — перекрасить
в `theme.text.muted`, чтобы не спорили визуально с часами за внимание.

## Зона файлов

`crates/app/src/bar/` — правая секция бара (виджеты клока, сети, звука,
раскладки, режима, проекта). Найти точный layout-код через
`ctx_search` по `bar/widgets/` — вероятно общий `right_section`/аналог
сборщика виджетов, не трогать сами виджеты по отдельности если
группировку можно решить на уровне контейнера (gap между группами).

## Канон

Только токены темы (`theme.text.muted` и т.п.), никаких новых hex.
Не менять сами иконки/контент виджетов — только spacing.

## Верификация

```bash
cargo build --release -p chronos
```

Live: `grim` бара в обеих темах, сравнить с находкой — видимые паузы
между группами на кадре, часы визуально отделены от трея.
