**Статус:** active. **Роль:** QA. Общие правила —
`docs/orchestration/agents/RULES.md`.

**Зона:** продуктовый код не правишь. Временные зонды допустимы — с откатом

## Базовая линия — снять ПЕРВОЙ

До любых выводов зафиксируй, что было до слайса: содержимое
`~/.config/chronos/workspace.toml` (или его отсутствие) и кадр бара. Без
базовой линии «плашка съехала» ничего не значит.

```
cat ~/.config/chronos/workspace.toml 2>&1
hyprctl layers | grep -A3 chronos
```

## Восемь проверок

1. **Виджет на месте.** Переключатель виден в правом кластере левее часов.
   CAVA осталась строго по центру, часы крайние справа. Кадр: `hyprctl layers`
   для геометрии слоя бара, затем `grim -g "x,y WxH"`.
2. **Клик работает.** Подпись и иконка меняются Developer ⇄ Gamer. Кадр до
   и после. Иконка **не пустая** — путь к несуществующему SVG в GPUI молча
   рисует пустоту, это ловится только глазами.
3. **Персистентность.** После клика в `~/.config/chronos/workspace.toml`
   появился `mode = "gamer"`. Показать `cat`.
4. **Переживает рестарт.** `chronos-stop && chronos-start`, режим тот же.
5. **Env перебивает конфиг.** `CHRONOS_WORKSPACE_MODE=developer` при
   `mode = "gamer"` в конфиге → поднялось в Developer. Конфиг при этом
   **не перезаписан**.
6. **IPC.** Три команды: `toggle-workspace-mode` переключает,
   `set-workspace-mode:gamer` ставит конкретный, `set-workspace-mode:мусор`
   игнорируется без паники и без смены режима. Сокет найдёшь в
   `crates/app/src/ipc/service.rs`.
7. **Плашка не крадёт фокус.** Детектора в этом слайсе нет, поэтому вызвать
   предложение можно только из кода — согласуй с архитектором временный
   способ (env-флаг с разовым `request_switch` в `init`), **и откати его
   после**. Проверка: `hyprctl activewindow` до появления плашки и после —
   активное окно то же. Затем «Не спрашивать» → в конфиге появился
   `prompt_prefs`, а `mode` **не потерялся**.
8. **Обе темы.** Кадры бара в тёмной и светлой (`CHRONOS_THEME` или
   `toggle-theme` по IPC). Плашка читается в обеих, ничего не сливается с
   фоном.

## Отдельно проверить — это важнее остальных восьми

**Режим не переключается сам.** Запусти шелл, открой игру или любое
полноэкранное приложение, поработай пять минут, подёргай окна. Режим обязан
остаться тем, что ты выбрал. Спека §1 запрещает автопереключение прямым
текстом, и это единственный пункт, нарушение которого делает слайс
непринимаемым целиком.

Плюс статическая проверка:

```
grep -rn "workspace_mode::set\|workspace_mode::toggle\|request_switch" --include='*.rs' crates/
```

Каждое место обязано быть пользовательским путём: клик, IPC, `accept_prompt`.
Найдёшь вызов из таймера, подписки на сервис или детектора — это находка
уровня «слайс не сдан», выноси в отчёт первым пунктом.

## Как запускать

```
chronos-stop && RUST_LOG='info,chronos=debug,chronos_services=debug' chronos-start
```

Лог: `~/.local/state/chronos/chronos.log`. Убивать только `pkill -x chronos` —
`-f` убьёт твою же оболочку.

## Что честно написать в отчёте

- Каждая улика — команда и её вывод целиком, кадр с командой `grim`, которой
  снят.
- Что не проверено и почему. «Не проверял» стоит ноль; галочка на
  непроверенном отклоняется.
- Любое расхождение с восемью пунктами плана — даже косметическое.
