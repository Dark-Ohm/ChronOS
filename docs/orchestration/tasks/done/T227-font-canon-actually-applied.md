# T227 — JetBrains Mono на самом деле шелл-широко (T215 закрыл не то)

**Статус:** active, не начата  
**Источник:** live dogfood 2026-08-03 — «левая панель JetBrains Mono не
использует»  
**Приоритет:** P1 — бьёт по консистентности, то есть по первому кадру
(`docs/PRODUCT.md` §1)

## Что на самом деле сделал T215

Коммит `4a7d9dd` «ui : JetBrains Mono shell-wide including gpui-component»
тронул четыре файла и сделал две вещи:

1. поменял **данные** дефолтной темы — `crates/ui/src/theme/mod.rs`:
   `font_ui: "Inter"` → `"JetBrains Mono"`;
2. прописал шрифт в тему **gpui-component** —
   `crates/app/src/theme_config.rs:130-136` (`font_family` + `mono_font_family`).

Виджеты gpui-component читают свою тему сами, поэтому редактор и инпуты в правой
панели шрифт получили — и результат выглядел как «шелл-широко». **Это была
иллюзия.**

## Настоящее положение дел (грепом по дереву)

`theme.font_ui` применяется **ровно в одном месте на весь шелл** —
`crates/app/src/system_popup/view.rs` (поэлементно: `:157`, `:254`, `:471`,
`:502`, `:551`, `:573`). Бар один раз ставит `font_mono`
(`crates/app/src/bar/mod.rs:140`). Левая панель — только `font_mono` на
tool-карточках (`side_panel_left/tool_card.rs:58,116,146`).

**Ни одно окно не задаёт семейство шрифта на корне.** Значит все собственные
вьюхи ChronOS — левая панель целиком, хром правой, уведомления, лаунчер, OSD,
док, трей, переключатель проектов — рисуются **дефолтным шрифтом GPUI**, а поле
`font_ui` в теме почти никто не читает.

## Решение

Шрифт должен применяться **один раз на корне каждого окна** и наследоваться
вниз, а не расставляться руками по элементам — ровно та болезнь, из-за которой
`font_ui` и оказался декоративным полем.

- Завести в `crates/ui` один хелпер (расширение стиля или функция-обёртка корня),
  который ставит `font_family(theme.font_ui)`, и применить его в корневом `div`
  каждого окна.
- Убрать поэлементные `.font_family(font_ui)` из `system_popup` — после корня
  они лишние и маскируют регрессии.
- `font_mono` оставить осознанно там, где нужен именно моноширинный смысл
  (tool-карточки, вывод команд, гуттер), а не «потому что так вышло». Сейчас
  оба поля равны `"JetBrains Mono"`, поэтому разницы не видно — но она вернётся,
  как только кто-то захочет разные лица, и код обязан выражать намерение.

## Зоны файлов

- `crates/ui/src/theme/` — хелпер применения
- корневые `render` каждого окна: `side_panel_left/panel.rs`,
  `side_panel_right/view.rs`, `bar/mod.rs`, `notifications/`, `launcher/`,
  `osd/`, `dock/`, `tray_menu/`, `system_popup/`, `volume_popup/`

Конфликт: `side_panel_right/view.rs` занят T216/T218/T219/T221 — брать после них.

## Приёмка

```bash
cargo test -p chronos --lib
cargo build --release -p chronos
```

Тест на дисциплину, а не на факт: перечислить корни окон и проверить, что
каждый проходит через хелпер. Проверка «`font_ui` равен JetBrains Mono» ничего
не доказывает — именно она и была зелёной всё это время, пока шелл рисовался
дефолтным шрифтом.

**Live (обязателен):** кадры `grim` каждой поверхности из списка зон в обеих
темах; сравнить начертание с редактором правой панели, который шрифт уже
получил. Особое внимание — левая панель: тред, композер, список сессий.

**Коммит:** `ui : apply theme font at every window root (T227)`.
