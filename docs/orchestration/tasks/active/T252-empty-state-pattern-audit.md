# T252 — единый паттерн "что показывать, когда нечего показывать" по вкладкам правой панели

**Приоритет:** P2 — системная/архитектурная задача, не точечный фикс.
**Роль:** дизайн-решение архитектора + возможный код после.
**Источник:** `docs/orchestration/tasks/report-log/T223-design-audit-report-v4-reshoot.md`
§4 "Системные проблемы", пункт 1; топ-10 п.10.

## Контекст

Аудит зафиксировал: System (перегружен фейковым моком T246 + пустой
mpris-карточкой T248), ACP agents (T249, голая пустота внизу) vs
Files/Editor settings (плотно, честно, к месту) — **три разных подхода**
к пустым/малосодержательным состояниям на трёх соседних вкладках одной
панели. T231-паттерн (`elevated_card` + `section_header`,
`crates/app/src/side_panel_right/tab/ui.rs`) уже унифицировал
ВИЗУАЛЬНЫЙ язык карточек, но не решение «пусто ли содержимое достаточно
ценное, чтобы занимать место».

## Что нужно

**Это не тикет на немедленную правку кода** — сначала решение, потом,
если нужно, отдельная задача на реализацию (как T240). Пройтись по всем
вкладкам `crates/app/src/side_panel_right/tab/*.rs` единым чек-листом:
для каждой — что показывается, когда данных нет/мало, и почему именно
так (свернуть? показать заглушку? зарезервировать место под будущий
контент?). Записать решение как паттерн (аналог `elevated_card`/
`section_header` в `ui.rs`, но для "empty state") — либо новый
хелпер в `tab/ui.rs`, либо просто задокументированное правило в
`docs/DECISIONS.log`, если код разный для каждого случая по разумной
причине.

**Зависимость:** имеет смысл делать ПОСЛЕ T246/T248/T249 (они закрывают
три конкретных случая из списка) — тогда паттерн выводится из уже
исправленных примеров, а не из абстрактного рассуждения.

### Вывод

Шесть легитимных приёмов (hero / inline / compact-collapse / скрытие /
растягивание до низа / placeholder) — код разный **по разумной причине**,
единый виджет был бы ошибкой. Решение = матрица выбора + планки-запреты,
дословно в `DECISIONS.log` 2026-08-13.

Найденный дрейф, который закрывает материализация: hero размножён вручную
4 раза (иконка 40 vs 32px, gap 12/10/8, opacity 0.55 через раз),
inline — 5+ раз с тремя разными оформлениями; «нет дисков» — единственная
русская строка панели.
