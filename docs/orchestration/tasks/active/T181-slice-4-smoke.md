## Механика, без которой смок не получится

**Панель раскрывается в два приёма.** Клик по иконке в рейле только
*выбирает* вкладку — панель остаётся шириной 54 px. Контент раскрывает
кнопка `⊞`/`⊟` **в самом низу рейла**. Признак в логе:
`apply per-tab width … content_open=false` — значит видно только рейл, и
любой твой «кадр вкладки» будет пустым. На этом уже потерялись двое.

Координаты на пульте (DP-1, 2560×1440):

| элемент | реальные | для `ydotool` (половина) |
|---|---|---|
| рейл, колонка иконок | `x ≈ 2537` | `x = 1268` |
| первая иконка (System) | `y ≈ 55` | `y = 27` |
| шаг между иконками | `40` | `20` |
| Files (2-я) | `y ≈ 95` | `y = 47` |
| Terminal (4-я) | `y ≈ 175` | `y = 87` |
| Preview (5-я) | `y ≈ 215` | `y = 107` |
| кнопка раскрытия контента | `x ≈ 2539, y ≈ 1414` | `1269 707` |
| строка `README.md` в Files | `x ≈ 2200, y ≈ 1017` | `1100 508` |

`ydotool` берёт **половинные** координаты (подтверждено девять раз), сокет
`YDOTOOL_SOCKET=/run/user/1000/.ydotool_socket`. Координаты строк в Files
меняются при навигации — снимай кадр и пересчитывай, не бери на веру.

IPC без рестартов, сокет `/run/user/1000/chronos.sock`, `socat` в системе
нет — шли так:

```python
import socket, sys
s = socket.socket(socket.AF_UNIX, socket.SOCK_STREAM)
s.connect("/run/user/1000/chronos.sock")
s.sendall(sys.argv[1].encode()); s.shutdown(socket.SHUT_WR); s.close()
```

Команды: `set-workspace-mode:developer`, `set-workspace-mode:gamer`,
`toggle-workspace-mode`, `toggle-side-panel-right`.

## Что проверить

### 1. Четыре вкладки живы одновременно

Открыть по очереди Files, Terminal, Build, Preview в одной сессии, без
рестарта. Каждая рисует своё, ни одна не ломает соседнюю. Кадр на каждую.

Ключевое, чего не проверял никто: **вкладки кэшируются**. Уйти с Terminal
на Files и вернуться — шелл тот же (тот же pid в логе), история на месте.
Уйти с Files и вернуться — каталог тот же, не сброс в `current_dir`.

### 2. Ленивость по всем четырём

Свежий старт, панель не открывалась. В логе **нет** ни `lazy-create tab
view` кроме System, ни `shell spawned`, ни `tab opened — loading tasks`,
ни `preview: loaded`. `pgrep` не показывает лишнего шелла (кроме фонового
`desktop_terminal` — он поднимается при старте, это нормально).

### 3. Ширина следует вкладке

Проверенные значения: System 400, Files 440, Terminal 560, Preview 560,
Build **640**. Пройти по всем и сверить с логом `apply per-tab width`.
Плюс `hyprctl layers` на ширину слоя хотя бы дважды.

Отдельно: потянуть хэндл на одной вкладке, уйти на другую и вернуться —
**ширина запомнена на вкладку** (T171).

### 4. Смена режима

`set-workspace-mode:gamer` — рейл сжимается до 7 иконок, Build/Preview/
Terminal исчезают. Если активной была одна из исчезнувших, панель
**не закрывается**, а сама переходит на System и берёт её ширину (T174).
`set-workspace-mode:developer` — 14 иконок вернулись.

### 5. Честные состояния (§13, §41) — предъявить кадрами

- Build без активного проекта: временно убрать `active` из
  `~/.config/chronos/projects.toml`, **потом вернуть**;
- Build: провальная задача — код возврата виден;
- Preview: ничего не выбрано; бинарь (`target/release/chronos`) —
  отказ с типом и размером; `.html` — `unavailable` с причиной;
- Terminal: убить шелл (`kill -9`) — баннер «Shell exited» и restart;
- Files: каталог без прав (`/root`) — честная ошибка, **это долг с T176,
  живьём не проверялся ни разу**.

### 6. Долги, закрываемые этим смоком

- **Отмена задачи в Build через UI** — в T178 `ydotool` не попал в кнопку.
  Запустить `cargo build`, нажать отмену, убедиться `pgrep`, что процесс
  умер, а не осиротел.
- **`/root` в Files** (см. выше).
- **Дельта размера бинаря от фичи `markdown`** — T179 включил её, замера
  никто не сделал. Собрать релиз с фичей и без (`--no-default-features`
  на воркспейс-строке `gpui-component`), два `ls -la`, разницу в отчёт.
  Ориентир для сравнения: T157 мерил `Input` +1.84 MiB, `Table` +199 KB.

## Как отчитываться

- каждый пункт — **PASS / FAIL / НЕ ПРОВЕРЕНО с причиной**;
- «не проверено» — законный ответ и засчитывается; выдуманное «работает» —
  нет;
- **если инструмент не смог — так и пиши: «не смог проверить
  инструментом», а не «функция сломана».** В T177 исполнитель объявил
  неработающей живую клавиатуру, потому что `ydotool` не доставил ввод;
- **кадры открывать глазами и подписывать тем, что на них.** В T177 два
  кадра были подписаны чужим содержимым, в T179 кадры оказались пустыми —
  и то и другое вскрылось при приёмке за минуту;
- лог целиком: `grep -n "panicked at"`;
- пультовый вывод бывает занят фуллскрин-игрой — занят, пиши «не
  проверено» с причиной, в игру не лезь.

Мелкое вырезать и увеличивать:

```
magick кадр.png -crop 580x900+1960+40 +repage -filter point -resize 200% out.png
```
