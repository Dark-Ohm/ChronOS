## Механика, без которой смок не получится

**Панель раскрывается в два приёма.** Клик по иконке в рейле только
*выбирает* вкладку — панель остаётся шириной 54 px. Контент раскрывает
кнопка `⊞`/`⊟` **в самом низу рейла**. Признак в логе:
`apply per-tab width … content_open=false` — значит видно только рейл, и
любой твой «кадр вкладки» будет пустым. На этом уже потерялись двое.

Координаты на пульте (DP-1, 2560×1440):

| элемент | реальные | для `ydotool` (половина) |
|---|---|---|
| рейл, колонка иконок | `x ≈ 2537` | `x = 1268` |
| первая иконка (System) | `y ≈ 55` | `y = 27` |
| шаг между иконками | `40` | `20` |
| Files (2-я) | `y ≈ 95` | `y = 47` |
| Terminal (4-я) | `y ≈ 175` | `y = 87` |
| Preview (5-я) | `y ≈ 215` | `y = 107` |
| кнопка раскрытия контента | `x ≈ 2539, y ≈ 1414` | `1269 707` |
| строка `README.md` в Files | `x ≈ 2200, y ≈ 1017` | `1100 508` |

`ydotool` берёт **половинные** координаты (подтверждено девять раз), сокет
`YDOTOOL_SOCKET=/run/user/1000/.ydotool_socket`. Координаты строк в Files
меняются при навигации — снимай кадр и пересчитывай, не бери на веру.

IPC без рестартов, сокет `/run/user/1000/chronos.sock`, `socat` в системе
нет — шли так:

```python
import socket, sys
s = socket.socket(socket.AF_UNIX, socket.SOCK_STREAM)
s.connect("/run/user/1000/chronos.sock")
s.sendall(sys.argv[1].encode()); s.shutdown(socket.SHUT_WR); s.close()
```

Команды: `set-workspace-mode:developer`, `set-workspace-mode:gamer`,
`toggle-workspace-mode`, `toggle-side-panel-right`.

## Как отчитываться

- каждый пункт — **PASS / FAIL / НЕ ПРОВЕРЕНО с причиной**;
- «не проверено» — законный ответ и засчитывается; выдуманное «работает» —
  нет;
- **если инструмент не смог — так и пиши: «не смог проверить
  инструментом», а не «функция сломана».** В T177 исполнитель объявил
  неработающей живую клавиатуру, потому что `ydotool` не доставил ввод;
- **кадры открывать глазами и подписывать тем, что на них.** В T177 два
  кадра были подписаны чужим содержимым, в T179 кадры оказались пустыми —
  и то и другое вскрылось при приёмке за минуту;
- лог целиком: `grep -n "panicked at"`;
- пультовый вывод бывает занят фуллскрин-игрой — занят, пиши «не
  проверено» с причиной, в игру не лезь.

Мелкое вырезать и увеличивать:

```
magick кадр.png -crop 580x900+1960+40 +repage -filter point -resize 200% out.png
```
