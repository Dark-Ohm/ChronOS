## Задача

Префикс в том же поле переключает провайдера. Без префикса — приложения
(T265-A/B). Набор фиксированный, не расширять «на всякий»:

| Префикс | Провайдер |
|---|---|
| `>` + пробел/сразу | команда в шелле (`$SHELL -lc`, cwd `$HOME`) |
| `/` или `~` | пути: дополнение каталога, Enter → `xdg-open` / терминал+cd |
| `=` | калькулятор (одно выражение, результат в выдаче, Enter → в буфер) |
| `?` | справка по этим режимам |
| `i:` | системная информация (hostname, kernel, compositor) — read-only строки |

`?` всегда доступен. Невалидный префикс не глотает ввод молча — либо
обычный app-search, либо одна строка «unknown prefix» плюс `?`.

Модуль `launcher/providers/` (по файлу на режим) + enum `Provider`.
`view.rs` не раздувать гигантом `match` в `refresh_results` без выноса.

Поиск «везде, включая файлы» без префикса — **не** делать: файлы только
через `/`/`~`. Иначе nucleo по домашнему каталогу убьёт кадр.

Калькулятор: без нового crate, если хватает `meval`/`evalexpr` уже в
дереве; иначе лёгкий crate в workspace, не тащить CAS. Ошибку выражения
показать строкой, не паникой.

## Нельзя

- Новый Input. Менять app-ranking T265-A.
- Свой REPL / «AI в лаунчере».
- `Source/gpui/`, `Cargo.lock` без нужды (crate калькулятора — да, в
  том же коммите, поимённый add).
- Спаун шелла на каждый кейстрок: debounce или только Enter для `>`.
  Выдача `>` может предлагать историю команд из `~/.config/chronos/launcher-shell-history.toml`
  (лимит 50), не сырой `~/.bash_history`.

## Зона

`crates/app/src/launcher/providers/**`, `search.rs` / `view.rs` — диспетчер
префикса. Не `side_panel_*`.

## Верификация

Юниты: разбор префикса; `=` `2+2` → `4`; `?` не пустой; без префикса
путь идёт в app-search.

Live: `> echo hi` выполняется; `~/Dow` дополняет; `= 1/0` не валит шелл;
`i:` показывает строки; Esc закрывает лаунчер из любого режима.
