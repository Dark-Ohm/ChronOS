повторить его, а не придумывать свой.**

## Решение (архитектор)

### 1. Рейл получает две группы

Сейчас `side_panel_right/rail.rs:56` рисует все вкладки подряд, затем
`div().flex_1()` (распорка), затем кнопку дока `⊞`/`⊟`. Поэтому «последняя
вкладка» физически оказывается вверху, а не внизу — просто порядком задачу не
решить.

Рейл становится: **[верхняя группа] · распорка · [нижняя группа] · кнопка дока**.
`System settings` по умолчанию уезжает в нижнюю группу — это и есть «внизу над
кнопкой дока».

### 2. Порядок и группа персистятся в новый `~/.config/chronos/panels.toml`

```toml
version = 1

[right.rail.developer]
top = ["system", "files", "preview", "hyprland_binds", "acp_settings"]
bottom = ["editor_settings"]

[right.rail.gamer]
top = ["system", "library", "captures", "acp_settings", "hyprland_binds"]
bottom = ["editor_settings"]
```

Имена — те же id, что понимает `PanelTab::parse_id` (`tabs.rs`, регистр и
дефис/подчёркивание уже нормализуются). Санитайз обязателен и повторяет контракт
`resolve_for_mode` (`tabs.rs:587`): неизвестные имена пропускаются с `warn`,
дубликаты схлопываются, **пустой результат откатывается к дефолту режима**, чтобы
рейл никогда не опустел. Вкладка, которой нет ни в одной группе, но которая есть в
наборе режима, дописывается в конец верхней группы — иначе правка конфига руками
может потерять вкладку навсегда.

### 3. Перестановка — стрелками, а не перетаскиванием

Пользователь сказал «передвигать». Тащить иконку в 28px по рейлу шириной 36 —
это ровно тот жест, который в T216 уже показал, как больно он взаимодействует с
resize-ручкой в 4px рядом. Берём проверенный паттерн бара: в Edit Mode у каждой
иконки появляются `▲`/`▼`, а на границе групп шаг переносит вкладку между верхней
и нижней. Плюс рамка `accent.primary.opacity(0.45)` вокруг иконки — как у бара,
чтобы режим читался одинаково на обеих поверхностях.

Если после живой примерки захочется именно drag — заводить отдельным T-ID поверх
готового персиста, не в этой задаче.

## Приёмка

```bash
cargo test -p chronos --lib side_panel_right
cargo build --release -p chronos
```

Тесты обязаны звать настоящий код (урок T164 — тест, переписывающий логику внутри
себя, ничего не доказывает):

- дефолт: `editor_settings` в нижней группе обоих режимов;
- санитайз: неизвестное имя пропущено, дубликат схлопнут, пустой конфиг → дефолт
  режима, забытая вкладка дописана в конец верхней;
- `move` вверх с первой позиции и вниз с последней — no-op, не паника;
- переход через границу групп меняет группу, а не индекс.

**Live (обязателен):** `Super+Shift+E` → у иконок рейла появились стрелки и рамка;
переставить вкладку, проверить `~/.config/chronos/panels.toml`; выключить Edit
Mode, перезапустить шелл — порядок сохранился; `System settings` стоит внизу над
`⊞`. Кадры `grim` в обеих темах.
