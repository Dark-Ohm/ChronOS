# BACKEND — точка входа роли

**Роль:** сервисы, протоколы, данные. D-Bus, Wayland/Hyprland IPC, ACP,
хранилища, фоновые задачи.

**Зона:** `crates/services/**`, `crates/luau/**`, `crates/plugins/**`.
UI не твой (это FRONTEND).

**Общие правила:** `docs/orchestration/agents/RULES.md` — прочитать перед стартом.

**Активные задания** (слайс 2 спеки Shell-IDE, план —
`docs/superpowers/plans/2026-07-31-shell-composition-slice-2.md`):

- `docs/orchestration/tasks/active/T166-pult-display-consolidation.md` —
  **ЭРРАТА, первый заход не принят.** Раздел «ЭРРАТА» в конце файла —
  читать его. Блокер: `pult_display_info` объявлена, задокументирована и не
  вызывается ни разу, а из четырёх поверхностей `.or_else` просто удалён —
  «фолбэк в одном месте» не существует. Плюс вотчер не стартует на первом
  запуске, живой прогон не сделан, и зона расширена ещё на четыре места
  (недосмотр архитектора при составлении списка).

**Зона в этой задаче — `crates/app/**`, а не `crates/services/**`.**
Это осознанное отступление от таблицы ролей, как было в T160: состояние и
резолверы шелла живут в `crates/app`. Точный список файлов — в самих
заданиях, он уже, чем «весь crates/app», и соблюдать надо именно его.

внутри себя (`if version == 0 { version = 1 }`), не тест, а копия. Эррата
закрыта чисто, все три пункта. Коммиты `5543a4a` + `8d82a12`.
