# Тема оформления Frame: Hide и Wrap

**Статус:** approved — план и бриф T284, 2026-08-15

**Канон референса:** внешний кадр (не ChronOS) — тёмная рамка по периметру,
внутренний скруглённый прямоугольник, бар визуально верх рамки

**Не заменяет:** T268 (`crates/app/src/frame.rs`). T268 остаётся путём
`style = "hide"` при видимых рельсах

**Следующий этап:** исполнение T284 по
`docs/superpowers/plans/2026-08-15-t284-frame-wrap-theme.md`

## 1. Цель

Добавить **тему оформления** рабочего стола, не меняя дефолтный шелл.

T268 закрыл только стык «полоска между рельсами». `RAIL_INSET = 40`
зашит всегда: рельсу убрали — по краям дыры. Этого в тикете не было.

Два режима, переключатель **Frame** во вкладке Appearance правой панели
(не чип пресета бара):

| Режим | Рельсы видны | Рельс нет |
|---|---|---|
| **Hide** (дефолт) | нижняя полоска рельса–рельса, T268 | полоски нет |
| **Wrap** | рамка по периметру, рельса *внутри* карточки | та же рамка, без рельс |

Клиенты (терминал, браузер) сидят **внутри** рамки: скругления всегда
видны, окна на хром не наезжают. Выключил Wrap — геометрия шелла как
была до включения.

## 2. Не входит

- Перепись дефолтной геометрии бара / рельс / hover-strip.
- Новый пресет в ряду `Top full` / `Bottom pill`.
- Запись в Hyprland (`gaps_out`, `decoration:rounding`, `10-look.lua`).
- Четвёртый цветовой токен. Хром = `theme.bg.tertiary` + `border.subtle`
  (T267).
- Exclusive zone у декоративной дырки (клик навылет, как у полоски T268).
- Мультимонитор: только пульт (`pult_display`), как у бара и T268.
- Видимый hover-strip как часть рамки; peek остаётся на физической кромке.

## 3. Конфиг

`~/.config/chronos/frame.toml`, тот же inotify + 300 ms debounce.

```toml
# hide | wrap  — отсутствует ключ = hide
style = "hide"

[bottom_strip]
enabled = true
height = 4.0
junction = "break"

[wrap]
inner_radius = 16.0
```

- `style` — новый ключ `FrameConfig`. Неизвестное значение → `hide` + warn,
  не падать и не молча включать Wrap.
- `bottom_strip.height` — толщина хрома обёртки и высота полоски Hide.
  Диапазон как сейчас (`1..=16`). Отдельной толщины Wrap нет.
- `wrap.inner_radius` — внутренние углы карточки, не половина высоты.
  Кламп `0..=64`, дефолт `16`. На высоте 4 px радиус 2 (T268 `rounded`)
  невидим; у обёртки радиус живёт на внутренней кромке, не на торце полоски.
- `bottom_strip.junction` действует **только** в Hide при видимых рельсах.
  Wrap его игнорирует.

Appearance пишет только `style`. Высота уже крутится через `frame.toml`;
в этом заходе новую крутилку радиуса в UI не обязательна — ключ в томеле
достаточен.

## 4. Hide

Предикат «рельса видна»: открыта rail-поверхность этой стороны
(40 px рельса или раскрытая панель). Hover-strip 4 px — **не** рельса.

- Обе рельсы видны → путь T268: junction `break`/`flush`/`rounded`,
  exclusive нет.
- Видна одна → inset только с её стороны (`RAIL_INSET` или 0).
- Ни одной → поверхность нижней полоски не создавать / закрыть.
  `enabled = false` по-прежнему гасит полоску независимо от рельс.

Пиксельный критерий: кадр Hide + обе рельсы совпадает с принятым T268
(`d572657`). Hide + без рельс — на нижней кромке нет хрома.

## 5. Wrap — поверхности

Тема, не новая архитектура шелла. Пока `style = "wrap"`:

1. **Рамка (рисунок).** Одно полноэкранное layer-shell окно на пульте.
   Красит матовый хром с дыркой — скруглённый прямоугольник.
   Внутренний inset = `bottom_strip.height` слева/справа/снизу;
   сверху inset = живая высота бара (бар уже top exclusive).
   Слой ниже Overlay-хрома (бар, рельсы, попапы), чтобы не закрасить виджеты.
   `set_input_region(Some(&[]))` — клик навылет везде, включая хром:
   ввод забирают exclusive-зоны и клиенты, не рамка.
2. **Три невидимых exclusive-полоски** left / right / bottom, толщина
   = `bottom_strip.height`. Окна отступают. Полоски без ввода
   (`input_region` пустой), чтобы не сожрать peek.
3. **Бар не двигаем.** Он остаётся top exclusive. В Wrap: фон бара =
   `bg.tertiary` (уже так), нижнюю границу бара снять — иначе линия
   режет «единую» рамку. Снял Wrap — граница возвращается.
4. **Рельсы сдвигаются внутрь на `height` только пока Wrap включён.**
   Левая: margin.left = height; правая зеркально; высота
   `display - bar - height` (якорь без BOTTOM — нижний margin мёртв;
   content `exclusive = -1` сам не отступит). Exclusive рельсы
   не включает левый/правый хром рамки (его держат полоски п.2).
   Hover-strip остаётся на физической кромке экрана (поверх хрома рамки),
   peek от безеля живой.
5. Выключили Wrap: закрыть рамку и три exclusive-полоски, вернуть origin
   рельс, вернуть границу бара, нижняя полоска снова по правилам §4.

Полноэкранная рамка **не** ставит себе exclusive zone: у fullscreen
`exclusive != 0` резервирует весь экран.

## 6. Appearance

`crates/app/src/side_panel_right/tab/bar_settings.rs`, блок Appearance —
сегмент **Frame**: `Hide` | `Wrap`. Пресеты бара не трогать.

Клик пишет `style` в `frame.toml`. Живой apply через уже существующий
watcher кадра, без рестарта.

## 8. Проверка

Юнит (мало, без пикселей):

- parse `style` / unknown → hide
- Hide: inset-функция (0/1/2 рельсы) на числах
- Wrap: inset бара сверху + height по трём сторонам; radius кламп
- toggle wrap→hide не оставляет exclusive > 0 в снимке состояния

Живое, release, пульт DP-1:

- `hyprctl layers` + `hyprctl clients`: в Hide exclusive рамки = 0,
  геометрии клиентов как до T284; в Wrap клиенты отступили на height
  слева/справа/снизу, сверху по-прежнему бар.
- `grim -g` четыре угла: Hide+рельсы = T268; Wrap — внутренний радиус
  виден, обои в «укусе» угла, хром без четвёртого оттенка, обе темы.
- Wrap + открытая рельса: рельса внутри карточки, не на физической кромке.
- Hide + рельсы сняты: нижней полоски нет.
- Клик в дырке и по хрому рамки доходит до клиента / peek, не до рамки.
- Обратный тумблер: клиенты вернулись, лишних слоёв в `hyprctl layers` нет.

«Компилируется и тесты зелёные» — не приёмка.

## 9. Решение, которое уже принято

- Это тема оформления, не изменение шелла (владелец, 2026-08-15).
- Переключатель — сегмент Frame в Appearance, не пресет бара.
- Клиенты внутри рамки.
- Обёртка не сдаётся, когда рельса выезжает: рельса садится внутрь.
- Сбор: одна рамка-рисунок + три exclusive-полоски; Hyprland не пишем.
- Дефолт Hide, кадр свежей установки без правки `frame.toml` = T268.
