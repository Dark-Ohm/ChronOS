# T331 — сетевой виджет влезает в HEIGHT_MIN

**HOLD 2026-08-21.** Пол 20 пересматривает **T337**. Не стартовать, пока
T337 не сдаст новый `HEIGHT_MIN`. Если новый пол вмещает две строки xs —
закрыть без кода (сеть больше не надо втискивать в 20).

**Роль:** FRONTEND. **P1.** Живая находка T324 B3.
**Зона:** `crates/app/src/bar/widgets/network.rs` (+ hot-reload twin, если есть).
**Не трогать:** `appearance.rs` / `HEIGHT_MIN` / `bar.toml` — это T337.

## Зачем

При `appearance.height = 20` (= `HEIGHT_MIN`, `appearance.rs:173`) вторая
строка спидометра обрезана посередине глифов. Продукт разрешает высоту,
на которой ломает свой виджет. Кадр:
`dump/qa-ux/T324/crops/40-network-clipped.png`.

Двухстрочная вёрстка `network.rs` (~216–231) не имеет однострочного
фолбэка. `font_sizes.xs` ≈ `base * 0.77` — две строки xs не влезают в 20px.

## Что сделать

Если высота бара (читай из конфига/темы бара, как соседние виджеты) не
вмещает две строки xs + зазор — **одна строка** (точка + ↓/↑ компактно),
без обрезки глифов. При высоте как дефолт ~42 двухстрочный вид остается.

Не делать виджет кликабельным в этом тикете (M2 T324 — TBD).
Не трогать мигание индикатора в этом тикете.

## Готово когда

Живой бар `height = 20`: обе строки/компакт читаются целиком, grim.
Вернуть height как было у владельца после смока (сейчас в системе 20 —
не затирай другие ключи, RMW). `height = 42` — регресс двух строк нет.
`cargo test -p chronos --lib` по network/bar не краснеет.
