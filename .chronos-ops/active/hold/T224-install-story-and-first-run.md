# T224 — Вход в воронку: пакет и первый запуск

**Статус:** **pause** (2026-08-03, рано) — упаковывать нечего, пока идёт волна
правой панели. Расконсервировать, когда дневной путь устоялся; ворота анонса и
проверка D6 описаны ниже в «Когда брать».  
**Источник:** цель 2026-08-03 — «чтобы люди переходили с винды на Linux+ChronOS,
потому что заманило» (`docs/PRODUCT.md` §1 «Северная звезда»)  
**Приоритет:** P0 по продукту, но с воротами по времени

## Факт, с которого всё начинается

На 2026-08-03 в репозитории **нет** `PKGBUILD`, нет `packaging/`, нет `dist/`.
Единственный «install» в `README.md:88` — `scripts/install-dev-cli.sh`, утилита
для разработчика. Все упоминания `pacman` в задачах относятся к попапу
обновлений, который pacman *потребляет*, а не к упаковке шелла.

Значит: постороннего человека, которого зацепил скриншот, **некуда вести**.
Сколько бы мы ни полировали панели, воронка обрывается на первом шаге.

## Когда брать

**Саму задачу — можно сразу, параллельно с чем угодно.** PKGBUILD, зависимости,
чистый снос и витрина README не касаются кода панелей и редактора; ждать их
незачем.

Ворота стоят **не на пакете, а на анонсе** — это разные события. Пакет может
существовать и обкатываться задолго до того, как о нём где-то написано.

Планка для анонса — **обещанный путь** (`docs/PRODUCT.md` §1): агент слева,
файлы справа, системные настройки, хром. Редактор в правой панели — вторичная
поверхность, и его полировка анонс не держит.

**Исключение, которое нужно проверить до анонса, а не предполагать:** корень
`docs/TBD.md` **D6** (цифры исчезают при наборе) неизвестен. Если он лежит в
слое ввода или в отрисовке глифов (T215 `4a7d9dd` сделал JetBrains Mono
шелл-широким, включая gpui-component), он бьёт и по композеру агента, и по
терминалу — то есть по ядру продукта. Если он в отрисовке буфера/гуттера
редактора — гейтит только себя.

Разводится за 15 минут без сборки: набрать `123abc` в композере агента, в
терминале и в редакторе. Где воспроизвелось — там слой. **Сделать это до
анонса.**

## Объём

### 1. Пакет

- `PKGBUILD` для Arch/CachyOS, сборка из исходников (`cargo build --release`),
  зависимости прописаны честно: Hyprland/Niri, wayland, шрифты (JetBrains Mono
  — шелл на неё завязан, T215), `ydotool`/`grim` только если реально нужны в
  рантайме, а не для наших смоков.
- **Снос обязан быть чистым.** `pacman -Rns` не должен оставлять процессов и
  layer-поверхностей; конфиги в `~/.config/chronos/` остаются (данные
  пользователя), но об этом сказано в выводе.
- Форк GPUI лежит path-зависимостью (`Source/`). Решить и **записать** в отчёте,
  как это упаковывается: вендоринг в тарбол, git-сабмодуль или отдельный пакет.
  Это главный технический вопрос задачи, не откладывать его на потом.

### 2. Первый запуск

- Дефолтный конфиг обязан давать рабочий шелл **без единой правки файла**: бар,
  панели, тема, обои, дефолтный агент. Если чего-то нет (например ACP-агент не
  настроен) — поверхность говорит об этом честно и по-человечески, а не пустотой
  (принцип «честности настроек» из T212).
- **Онбординг для человека с винды.** Он не знает биндов. Минимум: при первом
  старте видно, чем открыть меню и где настройки; вкладка Hyprland binds (T193)
  подаётся как «что нажимать», а не как справочник для своих.

### 3. Витрина репозитория

README — часть воронки, а не документация для нас:

- Первый экран: **кадр**, одна строка обещания, одна команда установки.
- Ответ на «зачем это вместо Waybar/Hyprpanel/DMS/end-4 dots» — двумя-тремя
  строками, честно: **бинарь-продукт, а не набор дотфайлов**; ставится и сносится
  пакетом; настройки кликаются; нет сети и телеметрии (сетевой guard T180).
- Никаких обещаний того, чего нет. Список «пока не умеем» лучше, чем тихая
  недосказанность: линуксоиды ловят это мгновенно и наказывают доверием.

## Приёмка

Проверка обязана идти **на чистой машине или в контейнере**, а не на машине
автора — здесь всё уже стоит, и это единственный способ поймать
незадекларированную зависимость.

```bash
# в чистом контейнере Arch
makepkg -si
# запустить, снять кадр, затем:
pacman -Rns chronos
```

Принимается, если: собралось из чистого дерева; шелл стартовал без правки
конфигов; снос не оставил мусора; в README первый экран отвечает на «что это и
зачем оно вместо X» без вранья.

**Коммит:** `packaging : PKGBUILD, first run, README front (T224)`.
