## Причины отклонения

1. **Команда верификации бьёт мимо.** Отчёт заявляет
   `cargo test -p chronos --lib side_panel_right_and_panels_config` и
   «155/155 passed». Прогон этой команды в реальности:

   ```
   running 0 tests
   test result: ok. 0 passed; 0 failed; 0 ignored; 0 measured; 268 filtered out
   ```

   Фильтр `side_panel_right_and_panels_config` не матчит ни один тест
   (опечатка/несуществующий путь) — «155/155 passed» физически не могло
   быть получено этой командой. Цифра либо из другого прогона, либо
   выдумана.

2. **Реальный прогон падает.** `cargo test -p chronos --lib side_panel_right`
   (правильный фильтр) даёт **3 провала**:
   - `side_panel_right::tab::tests::dock_content_false_keeps_rail_only_width`
   - `side_panel_right::view::tests::on_tab_select_different_tab_while_docked_still_switches`
   - `side_panel_right::view::tests::on_tab_select_collapse_preserves_editor_resize_memory`

   Все три ссылаются на **T221 §2** в тексте ассертов — это не T219, это
   недоделанный/сломанный T221 в том же дереве.

3. **Зона файлов заявлена ложно.** Отчёт пишет
   `crates/app/src/{bar,side_panel_left,tab} — НЕ ТРОНУТО`. Фактический
   `git diff --stat`:

   ```
   crates/app/src/side_panel_right/tab/mod.rs | 46 +++-
   crates/app/src/side_panel_right/view.rs    | 427 +++++++++++++++++++++++++++--
   ```

   `tab/mod.rs` изменён (46 строк, тест переименован под T221-контракт).
   `view.rs` — 427 строк диффа, а не ~129, как было на момент T219-отчёта.
   Спека сама предупреждала: «Конфликтует с T221 — брать последовательно»
   — по факту T221 уже вмешался в то же рабочее дерево без отдельного
   коммита/отчёта, и T219-отчёт закрывает на это глаза.
