# T262 — отчёт (второй заход): фикс цвета текста в Muted-состоянии

**Статус:** выполнено (код + живой прогон).
**Роль:** FRONTEND. **Приоритет:** P2.
**Ссылки:** разбор первого захода — `rejected/T262-volume-osd-redraw-report.md`
(коммит `e0c9cb7`); причина отказа №2 — расхождение «таблица эталона vs код».

## Выбранный путь: 1 — свести с таблицей эталона

Красным теперь является `text_secondary` — строка `{percent}%`/`mute`; `text_primary`
(`kind_label` — «Громкость»/«Микрофон») возвращён на `theme.text.primary` **всегда**.

### Почему именно путь 1

1. **Эталон подтверждает таблицу, а не код первого захода.** В `Volume-OSD.dc.html`
   вариант `.osd-v4` (Muted) красит **именно строку процента**:
   ```html
   <span style="...;color:#f38ba8;min-width:32px;text-align:right;">Mute</span>
   ```
   В Normal/Full/Low (`72%`/`100%`/`18%`) та же строка — `color:#cdd6f4`
   (обычный текст). Красный по эталону — маркер состояния muted на %-строке.
2. **`kind_label` в эталоне отсутствует.** «Громкость»/«Микрофон» — живое
   дополнение ChronOS (эталон показывает только иконку + трек + процент).
   Красить его красным в Muted — семантически неверно: «Громкость» не является
   признаком ошибки/выключения, это статичная подпись. Красный на ней был
   следствием того, что первый заход перепутал строки при переносе цвета.
3. **Осознанного отклонения заявлять нечего** — отклонение первого захода было
   неосознанным (отчёт утверждал красный на %-строке, код красил другую). Путь 2
   (оставить красный на `kind_label`) потребовал бы обосновать, почему живая
   подпись, которой нет в эталоне, краснеет вместо индикатора mute — такого
   обоснования нет.

## Что сделано

`crates/app/src/osd/view.rs` (`OsdView::render`), правка точечная — одна ветка
условия:

```rust
let text_primary = theme.text.primary;
let text_secondary = if muted {
    theme.status.error
} else {
    theme.text.secondary
};
```

- `text_secondary` (строка `mute`/`{percent}%`) → `status.error` при `muted`.
- `text_primary` (`kind_label`) → `theme.text.primary` всегда.
- Комментарий над веткой фиксирует привязку к эталону (`.osd-v4` Muted,
  `color:#f38ba8` на `Mute`).

Остальное (семантика заливки Normal/Full=info, Low=warning, Muted=error; твин
350ms `ease_out_quint`; фикс переполнения на `TRACK_W`) не трогалось — принято
по существу в разборе.

### Живой прогон (на живой Hyprland-сессии, обе темы)

Вызов OSD — штатный путь: `wpctl set-mute @DEFAULT_AUDIO_SINK@ 1` (событие
`AudioState` → подписчик → показ; без инъекции ввода). Геометрия OSD-слоя взята
из `hyprctl layers`: `xywh: 1120 1312 320 80`, namespace `osd` (DP-1, pult
display). Кадры — только `grim -g '1120,1312 320x80'` (никакого полноэкранного
grim, урок T260-wave2). Лог подтверждает оба показа:
`OSD: audio change is_source=false volume=1.2 muted=true` (21:12:42 и 21:14:17).

Кадры:
- `/tmp/t262-muted-theme1.png` — Muted, тёмная тема (трек `#313244`).
- `/tmp/t262-muted-theme2.png` — Muted, светлая тема (фон `#E0E3F4`).

Проверка пикселей (ImageMagick, зоны по геометрии карточки: иконка x≈16–44,
`kind_label` x≈56–200, строка `mute` x≈210–304, трек y≈32–48):

| Зона | Тёмная тема | Светлая тема |
|---|---|---|
| `mute` (x 210–304, y<32) | **красный** (x-раны 266–291, 295–301) | **красный** (x 266–301, 112 px) |
| `kind_label` (x 56–200, y<32) | 0 красных px | 0 красных px |
| Иконка (x<50) | 6 px (глиф эмодзи 🔇) | 5 px (глиф эмодзи 🔇) |

Красный в зоне `kind_label` отсутствует в обеих темах; красный текст
локализован строго в зоне строки `mute` справа. (Пиксели иконки — цветной глиф
эмодзи, `text_color` его не перекрашивает; присутствует в обоих кадрах
одинаково, к цвету текста отношения не имеет.)

Состояние после прогона восстановлено: `wpctl get-volume` = `1.20` (как было),
mute снят, тема возвращена двойным toggle.

### Известное наблюдение (не менялось, вне скоупа тикета)

При `muted` заливка трека рисуется на всю ширину по `fraction` (volume 1.2 →
1.0), цветом `status.error`. Эталон в `.osd-v4` задаёт `width:0%`. Это поведение
первого захода, принятое по существу в разборе; тикет ограничен цветом текста,
поэтому не трогалось. Фиксируется для полноты, при необходимости — отдельный
тикет.
