## Что НЕ сделано / не проверено живьём (честно)

- **Кадр пустого чата «No messages yet» не добыт.** Ретейн-сессия чат-колонки
  содержит сообщения, а IPC для создания пустой ветки нет — редьюсер
  `create_thread` (`side_panel_left/mod.rs:762`) достижим только через UI
  «+ New». Клик по «+ New» (ydotool-warping по рецепту FRONTEND.md,
  координаты сверял `hyprctl cursorpos`) не переключил на пустой чат —
  настаивать не стал, чтобы не плодить пустые сессии в списке владельца.
  Строка пустого состояния — та же замена одного токена, что и шеврон;
  её читаемость покрыта grep + воротами T317 (4.86:1 на фоне колонки,
  см. таблицу), а не живым кадром. Помечаю этот пункт **PENDING по живому
  кадру**, код-часть готова.
- **Пиксельная идентификация шеврона внутри кадра** однозначного A/B-диффа
  не дала (плотная раскладка чат-колонки, состояния кадров до/после
  частично различались). Доказательство невидимости «до» — точное совпадение
  цвета глифа с фоном (1.00:1 / 1.15:1), а не визуальный дифф кадров.
- Тест на label/action не добавлял — в брифе их нет (это не T334);
  поведение глифов — чистая замена токена, покрытая существующими воротами.
