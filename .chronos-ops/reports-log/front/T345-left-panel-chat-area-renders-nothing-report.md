# T345 — левая панель: чат-область не рисует ни сообщений, ни пустого состояния — ОТЧЁТ

**Роль:** FRONTEND. **Дата:** 2026-08-21. **Зона:** `crates/app/src/side_panel_left/chat_view.rs` — 1 файл, 11+/1−.

## Диагноз (сначала диагноз, потом правка)

Корень — **не в рендере пустого состояния, а в том, что оно никогда не наступает**: перед каждым
повтором/стартом turn'а в `chat.messages` пушится **пустой агент-плейсхолдер** с
`segments: Vec::new()`:

- `composer.rs:739-742` (`start_acp_turn`) — «Push a placeholder agent message (segments filled by streaming)»;
- `tabs/chat.rs:762-765` (`run_load_session`, `replay_into_chat=true`) — то же при повторе сессии
  (стартовый restore пустой/без транскрипта сессии → пустой плейсхолдер).

Из-за него `has_messages = !messages.is_empty()` был **true** даже для пустой сессии: ветка
`.when(!has_messages, …)` («No messages yet») не рисовалась, а плейсхолдер отрисовывался как
**один пустой пузырь-блок** (bg.secondary + border, ноль детей) — ровно то, что описал владелец:
«когда сессия пуста, есть один пустой пузырь-блок». При старте turn'а агент начинает писать в
него — пузырь наполняется, но до первого события сессия выглядит «пустой областью».

Это объясняет и расхождение T326 ↔ T344: T326 (Default, свежий чат без restore-плейсхолдера)
видел «No messages yet», а архитектор (Solarized, ретейнованная сессия → `run_load_session`
с `replay=true` → пустой плейсхолдер) видел пустую область. Не регрессия после T326 — состояние
зависит от загруженной сессии, как и допускал бриф.

## Правка

`crates/app/src/side_panel_left/chat_view.rs`:

1. `has_messages` теперь считается **по содержанию**, а не по длине списка:
   `self.messages.iter().any(|m| !m.segments.is_empty())` — пустой плейсхолдер не считается контентом.
2. В цикле рендера пустые сообщения **пропускаются** (`if msg.segments.is_empty() { continue; }`) —
   пузырь появляется только когда стриминг наполнит первый сегмент.

Загрузку сессии не трогал (это T281/T285): пустой плейсхолдер остаётся как приёмник стриминга,
просто не рисуется до наполнения.
