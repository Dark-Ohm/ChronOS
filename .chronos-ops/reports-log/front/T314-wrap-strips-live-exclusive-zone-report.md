# T314 — живая эксклюзивная зона wrap-полос: отчёт исполнителя (FRONTEND)

**Коммит:** `d93a5de6` — `frame : живая эксклюзивная зона wrap-полос — рельс становится кромкой кадра`
**Зона по брифу:** `crates/app/src/frame.rs` + точечно `content_window_margin` обеих панелей (промер показал расхождение — бриф разрешал).
**Бинарь:** `cargo build --release --bin chronos` (3m39s), предупреждения в `frame.rs` — только предсуществующие `never used` lib-таргета, новых нет.

## Что сделано

1. **`frame.rs`** — второй живой сигнал в `apply_wrap` рядом с `wrap_geometry_changed`:
   - `LAST_RAIL_MAPPING: AtomicU8` + `rail_mapping_bits()` + чистая `wrap_rail_mapping_changed(last, current)`;
   - `sync_wrap_excl_zones(cx, cfg)` — проход по живым хендлам `wrap_windows()`:
     `window.set_exclusive_zone(px(wrap_inset_left/right(&cfg, rail_mapped(...))))`
     для `ExclLeft`/`ExclRight` + `cx.notify()` на entity матте тем же сигналом
     (закраска и резервация меняются одним кадром). Результат `handle.update`
     не глушится — явный `match` с `tracing::warn` (урок ghost-window саги);
   - при смене маппинга — НЕ `close_wrap_windows`: пересоздание только по
     `geometry_changed`; mapping-only смена идёт живым проходом зон.
2. **`side_panel_left/mod.rs`, `side_panel_right/mod.rs`** — `content_window_margin`:
   промер показал контент на x=56 вместо 40. Корень: `set_rail_mapped(true)`
   вызывается ПОСЛЕ открытия обоих окон (CommitBoth), и живой `rail_mapped()`
   в момент расчёта маргина ещё `false` → запекался лишний `wrap.thickness`.
   Флаг заменён на инвариант сосуществования (`true` — контент открывается
   только вместе с рельсом). Больше в панелях не трогал ничего.
3. **Тест** `wrap_rail_mapping_changed_tracks_real_transitions` — реальные
   переходы (рельс появился/спрятан, второй рельс к первому, оба флипа сразу,
   steady-state), не тавтология `!=`.

## LAST_RAIL_MAPPING — отдельным абзацем

Бриф утверждал, что заготовка уже лежит в дереве (`frame.rs:921`) и предлагает
дать ей работу либо удалить. **Заготовки в дереве не было и никогда не было:**
`grep` — 0 совпадений, `git log -S LAST_RAIL_MAPPING --all` — единственный хит
`7a00b5ef` (кухонный коммит с самим текстом брифа). Видимо, инфраструктура
откатившегося захода T311 D3 так и не была закоммичена. Удалять было нечего;
создана с нуля и сразу получила работу (п. 1 выше). Мёртвой инфраструктуры
«на будущее» не оставлено.
