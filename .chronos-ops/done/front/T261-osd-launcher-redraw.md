# T261 — редизайн App Launcher по эталону Chronos-OSD-Launcher

**Приоритет:** P2 — визуальный редизайн, независимая зона.
**Роль:** FRONTEND.
**Эталон:** `docs/design/Chronos-OSD-Launcher.dc.html`.

## Контекст

Название эталона обманчиво — это НЕ OSD, это редизайн **аппового
лаунчера** (централ-оверлей поиска). Секции в HTML (по комментариям):
header, search, filter chips, results, footer, fine-tune panel,
high customization, launch feedback. Это заметно богаче текущего живого
лаунчера — там нет фильтр-чипов, "fine-tune panel", "launch feedback"
состояния. Прежде чем кодить — свериться с брифом: возможно, часть
секций (filter chips, fine-tune panel) — это фичи из будущего, не только
редизайн текущего. Если непонятно, что из эталона входит в скоуп «просто
перекрасить», а что требует новой логики — **остановиться и уточнить у
архитектора**, не кодить наугад с расширением скоупа.

Живой код: `crates/app/src/launcher/`:
- `view.rs` — `LauncherView`: input (высота `INPUT_HEIGHT=40`), список
  результатов (`ROW_HEIGHT=32`, до `MAX_VISIBLE_ROWS=10`), состояние
  `pattern`/`selected`/`results`.
- `search.rs` — `FuzzySearch` (логика подбора, не трогать, если задача
  чисто визуальная).
- `launch.rs` — запуск приложения (не трогать).

## Что нужно

1. Минимум (точно в скоупе): визуальная отделка `view.rs` под эталон —
   header/иконки/паддинги/радиусы/тени/цвета результата (выделение
   выбранной строки — сверить, как эталон подсвечивает активный
   результат: акцент-бар как в context-menu, или заливка целой строки).
2. Спорное (сверить с архитектором до кодинга, не тащить молча):
   filter chips, fine-tune panel, launch feedback анимация — если это
   новая функциональность, а не чистый рескин, это отдельный тикет
   (заведёт архитектор после ревью брифа), не часть T261.
3. Тема — `chronos_ui::Theme`, тот же принцип, что в T260: новый цвет
   эталона без соответствующего токена — завести токен, не хардкодить.

## Зона файлов

`crates/app/src/launcher/**`. Не трогать `crates/app/src/tray_menu/**`,
`crates/app/src/dock/context_menu.rs` (T260), `crates/app/src/osd/**`
(T262) — параллельные задачи.

## Верификация

- Живой прогон лаунчера (открыть через штатный биндинг), пустой запрос
  и запрос с результатами, обе темы.
- `grim -g` по геометрии из `hyprctl layers`.
- Сверить визуально с эталоном.

## Коммит

`launcher : редизайн по Chronos-OSD-Launcher эталону`. Без AI-трейлеров.
Общие правила — `docs/orchestration/agents/RULES.md`.
