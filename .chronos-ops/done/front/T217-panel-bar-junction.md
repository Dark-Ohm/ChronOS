# T217 — Верхняя кромка панелей должна честно стыковаться с баром

**Статус:** active, не начата (в дереве только замер)  
**Источник:** live dogfood 2026-08-03 — «верхняя часть панели при соединении с
баром красиво сливается с ним, не портя общий вид (и даже улучшая его)»  
**Приоритет:** P2 visual polish  
**Порядок:** брать **после** коммита T216 и T218 — те же файлы
(`side_panel_right/{mod,view}.rs`), иначе конфликт.

## Замер (факт, не гипотеза)

`~/.config/chronos/bar.toml`:

```toml
[appearance]
edge = "top"
elevation = "soft"
exclusive = true
floating = false
height = 34.22869110107422
radius = 16.0
width = "fraction:0.7"
```

`hyprctl layers`, монитор DP-1 2560×1440:

```
bar                     xywh: 384  0 1792 34
side_panel_hover_strip  xywh: 2556 34    4 1405
```

Читать так: бар — **пилюля** с радиусом 16, занимает x 384..2176. Панель живёт у
правого края (x 2520..2560 в rail-only). **Над панелью бара нет** — там пустой
рабочий стол, — но панель всё равно начинается с y=34, уступая место бару,
которого в этом месте не существует. Мёртвой щели между ними нет (34 = 34), стык
именно что читается как случайный, а не как задуманный.

## Что делаем

Стык должен выглядеть намеренным при любой конфигурации бара:

1. **Кромка в кромку.** Верх панели обязан совпадать с низом бара точьв-точь.
   Сейчас это совпадает случайно (оба 34); закрепить вычислением и тестом, а не
   надеждой. Источник истины — живая высота бара, уже опубликованная через
   `crate::state::bar_height_px()` (`crates/app/src/state.rs:118`).
2. **Скругление верхних углов панели.** Когда верхняя кромка панели свободна
   (бар — пилюля/floating, то есть по X её не накрывает), панель получает радиус
   верхних углов, равный `[appearance] radius`, и рифмуется с баром. Когда бар
   тянется во всю ширину и они стыкуются вплотную — радиус 0, иначе на стыке
   вылезет полукруглый шов.
3. **Обе панели и обе hover-полосы** ведут себя одинаково. У T204 уже есть
   кросс-панельный тест консистентности (`side_panel_left/mod.rs:1284
   rails_and_handles_match_right_panel`) — расширить его, а не заводить второй
   набор констант.
4. **Светлая и тёмная** — обе. Радиус/кромка не должны давать светлого канта на
   тёмной теме и наоборот.

### Что публиковать из бара

`state.rs` уже держит живую высоту бара атомиком, потому что `bar` — bin-only, а
панели — lib. Тем же паттерном добавить то, чего не хватает: радиус и
горизонтальный охват (накрывает ли бар полосу X, где стоит панель). Писать их
там же, где пишется высота — `bar::apply_appearance` и `bar::init`
(`crates/app/src/bar/mod.rs:432`, вызов `set_bar_height_px`).

## Отклонённая альтернатива (в DECISIONS.log, не переоткрывать)

**«Поднять панель на всю высоту до y=0.»** Технически это `exclusive_zone = -1` —
единственный способ игнорировать чужую зону в wlr-layer-shell. Но значение одно на
поверхность: панель либо игнорирует чужие зоны, либо резервирует своё место. Сейчас
она резервирует ширину (`exclusive_edge: RIGHT`, `mod.rs:180-181`), и это нужно —
иначе окна поедут под рейл, ломая T204/T206. Менять функциональность ради
косметики не будем.

## Зоны файлов

- `crates/app/src/state.rs` — живые геометрия/радиус бара (паттерн `bar_height_px`)
- `crates/app/src/bar/mod.rs` — публикация в `apply_appearance` + `init`
- `crates/app/src/side_panel_right/{mod.rs,view.rs,hover_strip.rs}`
- `crates/app/src/side_panel_left/{mod.rs,panel.rs,hover_strip.rs}`

Не трогать: `tabs.rs`, `tab/`, всё, что вне списка.

## Приёмка

```bash
cargo test -p chronos --lib side_panel        # включая кросс-панельный тест
cargo build --release -p chronos
```

Живой прогон обязателен — «зелёные тесты для оконного кода ничто»:

```bash
hyprctl layers | grep -E 'namespace: (bar|side_panel)'
```

- верх панели == низ бара при `width = "full"`;
- при `width = "fraction:0.7"` и при `floating = true` верхние углы скруглены по
  `radius`, шва нет;
- `grim` в обеих темах, глазами: сверху справа не должно быть ощущения обрезка.

Проверить все три конфигурации бара (правятся в `~/.config/chronos/bar.toml`,
хот-релоад при сохранении, рестарт не нужен): `full` / `fraction:0.7` / `floating`.

**Коммит:** `panels : top edge meets the bar cleanly (T217)`.
