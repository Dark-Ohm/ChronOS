# T302 — левая панель: контентная зона рендерится пустой, сквозь неё видны обои

**Роль: FRONTEND.** Найдено архитектором живьём при приёмке T298
(2026-08-17), не связано с диффом T298 — заведено отдельно.
**Приоритет:** P1 — панель формально открыта (rail + layer живы), но
содержимое не видно вообще, шелл фактически бесполезен в этом
состоянии для чата/композера.

## Контекст

Живой прогон (`chronos-start`, релизный бинарь, коммит `a98139b4`+):
`chronos-ipc toggle-side-panel-left` открывает панель —
`hyprctl layers` подтверждает оба layer'а живы и в разумных
координатах:

```
Layer ...: xywh: 40 30 920 1410, a: 1, namespace: side_panel_left_content, pid: ...
Layer ...: xywh: 0 30 40 1410, a: 1, namespace: side_panel_left_rail, pid: ...
```

Рейл (40px полоса иконок слева) рисуется. Контентная зона (920px)
**прозрачная — сквозь неё виден рабочий стол/обои**, ни чата, ни
композера, ни empty-state чрома не видно. `grim -o DP-1` полного
экрана подтверждает: только бар сверху и тонкая полоска рейла слева,
остальное — фон.

В логе (`RUST_LOG=chronos=info`) на момент открытия панели —
**ни одного error/panic/warn**, процесс не падает, просто не рисует
контент.

## Гипотезы (не проверены, для старта — не факты)

- Активная сессия ACP не поднялась (T285 STOP — `attach_session`
  приватный в `agent-client-protocol` 2.0.0) → `chat_view` может
  рендерить пустое дерево вместо empty-state, если ветка
  «нет сессии» не покрыта.
- Возможна регрессия от чужого некоммиченного WIP в `composer.rs`
  (на момент находки в дереве была параллельная незакоммиченная
  правка T298 от другой сессии — если её слили неаккуратно, часть
  дерева вьюхи могла выпасть).
- Может быть чисто про порядок инициализации: панель открылась до
  того, как что-то (тема? тред?) успело подгрузиться, и обновление
  перерисовки не подписано на нужный сигнал (паттерн T279/T296 —
  «баг не в логике, а в отсутствующей подписке на сигнал»).

## Задача

1. Живым прогоном (`RUST_LOG=chronos=debug`) открыть панель, смотреть
   что реально рендерится в `side_panel_left/mod.rs`/`chat_view.rs` —
   есть ли активная вкладка вообще, какой ветвление в `render()`.
2. Найти корень, не гадать — три гипотезы выше не проверены, могут
   быть все неверны.
3. Фикс + живой grim до/после, тот же рецепт `hyprctl layers` →
   координаты → `grim -g`.
